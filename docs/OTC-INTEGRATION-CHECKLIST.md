# Checklist OTC

- Dados vêm do mercado OTC observado na plataforma.
- Somente preço/candles são processados.
- Candle M1 é fechado antes da análise.
- Timestamp é preservado.
- Sinal fica congelado até a próxima vela/resultado.
- Histórico identifica `quotex_otc`.
- Nenhuma ordem é enviada pela integração.
