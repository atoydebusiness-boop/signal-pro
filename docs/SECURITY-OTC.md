# Limites do coletor OTC

O coletor desta etapa deve observar exclusivamente dados de mercado necessários à análise: ativo, timestamp, preço e/ou OHLC.

Não armazenar nem encaminhar: senha, cookies, tokens de sessão, cabeçalhos de autenticação, dados pessoais, saldo, depósitos, saques ou mensagens de execução de ordens.

O Signal Pro continua sendo um analisador; esta integração não implementa clique automático, compra, venda ou alteração de valor na corretora.
